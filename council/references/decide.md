# Decide mode

Use this mode for a hard question that has no artifact yet: strategy, pricing, which option to pick, or an architecture fork. Seat the same three labs as in Review mode.

## Step 1: Answer alone

Each seat gets the question, the constraints and compact facts, and answers independently:

```
RECOMMENDATION: <one option>
CONFIDENCE: <n>/10
STRONGEST EVIDENCE: <2-3 bullets>
DOUBTS: <what you are least sure of>
WOULD CHANGE MY MIND: <the fact that would flip it>
```

For business questions, pull compact context first from the user's own notes, if your setup has a notes or search tool. Seats on the user's own sign-ins may see that context. A paid outside route gets it only after redaction.

## Step 2: Rank blind

Shuffle the three answers, label them A, B and C, and remove model names. Send them back to every seat, which replies:

```
RANKING: <best> > <middle> > <worst>
STRONGEST POINT ANY ANSWER MADE:
BIGGEST BLIND SPOT:
WHAT ALL THREE MISSED:
```

## Step 3: Chair

You are the chair. Write:

- agreements and disagreements
- the best case for each viable option
- the recommendation and your confidence in it
- the assumptions behind it
- what would make it wrong
- the next action

The council **agrees** only when every seat ranks the same option first. Anything less is a chair recommendation with the dissent shown next to it. One rebuttal round is allowed: send the chair draft back, and stop after that round whatever the result.

Cap: two rounds. A decision has no artifact to fix, so more rounds only add noise.
