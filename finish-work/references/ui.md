# Interface Closeout

Inspect the changed interaction in the running app at relevant desktop and mobile sizes. Include meaningful empty, error and loading states where the change affects them. Preserve readable content, clear controls and coherent layout.

Use screenshots or a short recording when they substantiate the result. Inspect relevant console errors; fix issues caused by the change. If the requested browser tool is unavailable, use an existing project QA harness where possible and state what remains unverified.

For visual and media artifacts, use their task-specific review standards. An export or screenshot alone does not prove audiovisual quality or an interactive workflow.
