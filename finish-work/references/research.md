# Research And Document Closeout

Check the answer against the request and supporting sources. Distinguish current verification from memory, inference and unavailable evidence. Preserve exact quotations, locked copy, citations and proof states.

For document edits, inspect the completed artifact and relevant links and formatting. Use document-specific tools only when they help validate the deliverable. No codebase map, test suite or deployment is required for advice or prose alone.

A recommendation is complete when the requested analysis is delivered. Do not implement the recommendation unless the user authorizes implementation. Record the actual scope and any coverage gaps through receipt.md.
